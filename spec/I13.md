# I-13 canonical language surface

## The thirteen

```text
I
Name
Constant
Attribute
Assign
Arg
Return
Expr
If
Compare
Call
FunctionDef
BinOp
```

`I` is the concrete declaration keyword. The other twelve are the semantic verbs from the frozen I-13 brief.

`Block` is a load-bearing container, not a thirteenth verb.

## Four planes of three

```text
DESIGNATE : Name, Constant, Attribute
BIND      : Assign, Arg, Return
DECIDE    : Expr, If, Compare
TRANSFORM : Call, FunctionDef, BinOp
```

## Concrete syntax

```text
I x <- 0
-> x
{ ... }
// comment
```

Two-character tokens include:

```text
<- -> <= >= == !=
```

Constants are `f64` in the frozen brief.

## Canonical execution-frame law

`I13-EXEC-LIMIT-001`

```text
I13_FRAME_LIMIT = 4096
```

The limit counts all active I13 execution frames, including the main/root frame.

A `Call` is legal only when pushing its callee would keep the active I13 frame count at or below `4096`.

```text
root/main = frame 1

current_frames < 4096
        ↓
      Call
        ↓
current_frames + 1

current_frames >= 4096
        ↓
      Call
        ↓
      VETO
```

This is an I13 execution rule, not a host-stack preference. Every execution backend must enforce the same ceiling independently of the Rust, WebAssembly, operating-system, or other host stack capacity.
