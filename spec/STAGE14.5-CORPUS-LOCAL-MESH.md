# Stage 14.5 — Queen Local Neighborhood / Mesh Field

Status: live H1.1 browser layer.

## Purpose

Stage 14.4 established the exact `x16 | y16` OLOGY position field for all 54 admitted corpus roots. Stage 14.5 adds **local topology** without drawing all 187 undirected corpus edges at once.

At the Queen's current root, the browser asks the Stage 14.2 Rust/Wasm ABI for the exact admissible neighbor set:

```text
Q @ <x,y>
  |
  +-- i13_corpus_neighbor_count(root, evidence_only)
  |
  +-- i13_corpus_neighbor(root, slot, evidence_only)
          |
          +-- address : u32  -> neighbor OLOGY root
          +-- flags   : u8   -> edge provenance
          +-- weight  : u8   -> compiled edge strength
```

The JavaScript layer does **not** rebuild graph topology from JSON and does not grant movement or commit authority.

## Edge provenance

The Rust core defines:

```text
0x01 = EDGE_DOMAIN
0x02 = EDGE_WORLD_PATH
0x03 = both
```

`weight` is generated by `build.rs` from shared-domain multiplicity plus the heavier curated World-path contribution. Stage 14.5 displays those compiled values; it does not invent new semantic weights.

## Visual contract

Only edges incident to Q's current root are rendered.

```text
                 neighbor
                    o
                   /
          o ------ Q ------ o
                 / \
                o   o
```

- Q/current root: topology center.
- domain edge: local semantic relation.
- World edge: curated World-IV route relation.
- domain+World edge: both provenance bits present.
- `NEXT`: the neighbor selected by Wasm `walk_next()` toward the current goal.
- `PENDING`: the Stage 14.3 candidate awaiting voxel/CV exit.
- clicking a neighbor opens the Stage 14.4 root/voxel preview only; it does not move Q.

## Authority boundary

```text
Stage 14.5 click neighbor
        -> preview / inspect only

Stage 14.3 STEP
        -> Wasm walk_next
        -> candidate
        -> c[v[ ... ]]cv]
        -> PASS
        -> commit next root
```

Stage 14.5 owns **visual topology only**.

## Evidence mode

When Stage 14.3 evidence-only mode is active, Stage 14.5 calls the same Wasm neighbor API with `evidence_only=1`. Context/Vogel roots are therefore excluded by the Rust walker rather than hidden cosmetically in JavaScript.

A contextual/Vogel current root has zero admissible evidence-only neighbors because the Stage 14.2 policy rejects traversal from a non-evidence source in evidence mode.

## Non-claims

- OLOGY coordinate proximity is not network proximity.
- local mesh edges are corpus semantic/curated edges, not physical links.
- the browser overlay does not independently authorize movement.
- an edge being present does not promote a Vogel/context node into evidence.
