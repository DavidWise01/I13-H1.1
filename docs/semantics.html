MEANING ROCKS

Nine distinctions that survive syntax.

Each successful rock is HIR-inspected, executed by the reference VM, lowered to Wasm and checked for parity.

00

Representation

Value identity survives binding, call and return. Attached Function+Number bank witness must veto.

01

Precedence

2 + 3 * 4 == 14; the HIR structure itself is regression-checked.

02

Association

20-5-3 differs from 20-(5-3).

03

Scope

A function parameter wins over a same-named global while the global remains intact.

04

Binding modes

Ordinary assignment replaces; .p osmotic binding accumulates. Both HIR modes are asserted.

05

Return/control

A taken return decides the result; the fallback remains meaningful on the untaken path.

06

Arity

Declared arguments define legal Call shape. Wrong arity is E0203.

07

Named call

Declared function names resolve; unknown names are E0202.

08

Equivalence

Compact and multiline/grouped source forms preserve the same executable result.

BANK WITNESSES
