# Stage 13 — H1.0 freeze boundary

Stage 13 mounts the existing `freeze` trunk row into the bounded exploded-view system.

The source contract is `spec/H1.0-BOUNDARY.md`:

```text
H1.0 is frozen.
H1.1 may reference but must not silently mutate it.
```

## Controls

```text
RESET      return to frozen item 1
ITEM +     cycle across all eight carried facts
VERIFY     create a reference-verification receipt for the selected fact
BOUNDARY   show/hide the H1.0 | H1.1 semantic-change wall
RECEIPT    inspect the immutable boundary receipt
```

There is deliberately **no edit/mutate control** for H1.0.

## Boundary graphic

The OUTPUT box contains a clipped two-side boundary:

```text
H1.0 · FROZEN  |  H1.1+ · LIVE
```

The center wall marks the rule:

```text
semantic change -> H1.1+
```

The graphic is clipped to the OUTPUT box and cannot paint outside its boundary.
