☠ Malbolge — Spec Reference

Ben Olmstead, 1998. Named after the 8th circle of Hell (Malebolge, Dante). A deliberately near-unprogrammable esolang. Sourced from the full Wikipedia article.
This is a REFERENCE, not a runner. Malbolge's self-modifying ternary VM is notoriously subtle; a faithful interpreter is non-trivial and is out of scope for a static artifact. The data below is transcribed verbatim from the fetched article — all real, none fabricated.

The 8 Instructions (dispatch = (([c] + c) mod 94))

Crazy Operation — ternary lookup

crz(input1, input2): for each ternary digit use the table; e.g. crz 0001112220, 0120120120 = 1120020211.

Encipherment (post-step self-modification)

After each instruction, [c] is replaced with (its value mod 94) enciphered via this 94-char permutation; the ASCII code of the result is stored back at [c].
