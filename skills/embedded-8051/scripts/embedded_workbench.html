Register banks 0-3 occupy internal RAM 0x00-0x1F; RS1:RS0 in PSW selects the active bank. 128 bytes IRAM (0x00-0x7F) + 128 SFR (0x80-0xFF). External XRAM via MOVX; code via MOVC.

8051 DIP-40 Pinout

Ports: P0 = open-drain (needs pull-up, multiplexed AD bus); P1/P2/P3 = quasi-bidirectional with internal pull-up. P3 carries the alternate functions (serial, ext-int, timers, RD/WR).
