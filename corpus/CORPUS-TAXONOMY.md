# H1.1 technical corpus taxonomy

Primary lanes:

- ternary / mixed radix / computer arithmetic
- linear algebra / matrix / tensor / vector calculus
- Hamiltonians / integrable systems / differential equations
- fractals / chaos / nonlinear dynamics
- Ada Lovelace / Babbage / Analytical Engine
- DOS-era software / QBasic / QuickBASIC / Turbo Pascal / Fractint
- graphics / 3D / volume representation
- Sonia/Sonya/Sofya Kovalevskaya technical branch

V-layer:

```text
vector = mathematical/state-space structure
voxel  = spatial/nested-volume structure
vogel  = playful/non-serious/context lane; never evidence by itself
VS     = explicit comparison/contrast
```

A Vogel item may be promoted into a technical lane only after verification.

The corpus stores metadata, provenance URLs, classification and short original notes. It does not redistribute full copyrighted books/software simply because they are indexed.
